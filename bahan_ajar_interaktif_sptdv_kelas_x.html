Bagian 1 • Konsep Dasar & Sistem Linear

Pertidaksamaan & Sistem Pertidaksamaan Linear Dua Variabel

Pertidaksamaan Linear Dua Variabel (PtLDV) adalah kalimat terbuka yang memuat dua variabel (misalnya x dan y) berderajat satu dan dihubungkan dengan tanda ketidaksamaan (<, >, ≤, atau ≥). Jika terdapat dua atau lebih PtLDV yang digabung menjadi satu kesatuan, disebut Sistem Pertidaksamaan Linear Dua Variabel (SPtLDV).

Bentuk Umum PtLDV & SPtLDV:

ax + by < c  |  ax + by ≤ c  |  ax + by > c  |  ax + by ≥ c

Dengan a, b = koefisien (tidak keduanya nol), dan c = konstanta.

Langkah Menentukan Daerah Himpunan Penyelesaian (DHP):

  1. Ubah tanda pertidaksamaan menjadi tanda sama dengan (=) untuk menggambar garis batas.
  2. Tentukan titik potong terhadap sumbu-X (syarat y = 0) dan sumbu-Y (syarat x = 0).
  3. Perhatikan jenis garis: Putus-putus (- - -) untuk < atau >, dan Garis Penuh (—) untuk ≤ atau ≥.
  4. Uji Titik (misal titik (0, 0) jika tidak dilalui garis). Jika bernilai BENAR, arsir daerah yang memuat titik uji tersebut.

📌 Contoh Soal Modul (Halaman 10):

Tentukan DHP dari pertidaksamaan linear dua variabel: x - 2y ≤ -2

1. Persamaan garis batas: x - 2y = -2

2. Titik potong: jika y = 0 → x = -2 didapat (-2, 0); jika x = 0 → y = 1 didapat (0, 1).

3. Uji titik (0, 0): 0 - 2(0) ≤ -2 → 0 ≤ -2 (SALAH). Maka arsiran menjauhi titik (0, 0) (ke arah atas kiri garis).

Sistem Pertidaksamaan Dua Variabel Linear–Kuadrat (SPtDVLK)

SPtDVLK adalah kumpulan beberapa pertidaksamaan yang sedikitnya memuat satu pertidaksamaan linear dan satu pertidaksamaan kuadrat dua variabel.

Bentuk Umum SPtDVLK:

y * ax + b
y * px² + qx + r

Keterangan:

• Tanda * adalah <, >, ≤, atau ≥

• Variabel: x dan y

• Koefisien: a, p, q | Konstanta: b, r

Langkah Menggambar Pertidaksamaan Kuadrat (Parabola):

1. Arah Terbuka Kurva (Nilai p) Jika p > 0 parabola terbuka ke atas (∪). Jika p < 0 parabola terbuka ke bawah (∩).
2. Titik Potong Sumbu-X & Y Sumbu-X (syarat y = 0, faktorkan). Sumbu-Y (syarat x = 0, didapat titik (0, r)).
3. Titik Puncak (xₚ, yₚ) xₚ = -q / (2p) dan yₚ = -D / (4p) dengan D = q² - 4pr.
4. Irisan Daerah (DHP) Arsir daerah masing-masing, lalu tentukan irisan yang memenuhi kedua pertidaksamaan.

📌 Contoh Soal Modul (Halaman 12–13):

-x + y ≤ 1
y ≥ x² - 4x + 1
  • Garis -x + y = 1: melalui (-1, 0) dan (0, 1). Uji (0, 0) → 0 ≤ 1 (Benar, arsir ke bawah kanan garis).
  • Parabola y = x² - 4x + 1: terbuka ke atas (a = 1 > 0), titik puncak di (2, -3), memotong sumbu-Y di (0, 1). Uji (0, 0) → 0 ≥ 1 (Salah, arsir di dalam parabola).
  • Irisan DHP: Daerah di bawah garis lurus sekaligus di dalam lengkungan parabola (lihat grafik di samping).

Sistem Pertidaksamaan Dua Variabel Kuadrat–Kuadrat (SPtDVKK)

SPtDVKK adalah kumpulan beberapa pertidaksamaan yang memuat paling sedikit dua pertidaksamaan kuadrat dua variabel (semua pertidaksamaan pembentuknya berbentuk kurva kuadrat / parabola).

Bentuk Umum SPtDVKK:

y * ax² + bx + c
y * px² + qx + r

Catatan Penting:

• Kedua kurva digambar pada satu bidang Kartesius.

• DHP adalah irisan dari kedua daerah arsiran parabola.

📌 Contoh Soal Modul (Halaman 20–21):

Tentukan daerah penyelesaian dari sistem pertidaksamaan: y ≥ x² - 4 dan y < -x² - x + 2

1. Parabola pertama (y ≥ x² - 4):

• Terbuka ke atas (a = 1 > 0), puncak di (0, -4), memotong sumbu-X di (-2, 0) & (2, 0). Karena tanda ≥, kurva digambar garis penuh dan diarsir ke dalam/atas.

2. Parabola kedua (y < -x² - x + 2):

• Terbuka ke bawah (a = -1 < 0), puncak di (-0.5, 2.25), memotong sumbu-X di (-2, 0) & (1, 0). Karena tanda <, kurva digambar putus-putus dan diarsir ke dalam/bawah.

3. Irisan DHP: Daerah berbentuk lensa di antara kedua parabola tersebut!

💡 Tahukah Kamu? Penerapan SPtDVKK

Dalam modul KD 3.4 (Halaman 22), SPtDVKK digunakan untuk memodelkan rentang berat badan ideal (W) terhadap tinggi badan (h) serta pemodelan lintasan proyektil dan batas keamanan konstruksi jembatan lengkung.
